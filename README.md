## Markdown (md) Nedir? :
   Markdown, metinleri # veya * gibi basit semboller kullanarak hızlıca biçimlendirmemizi -başlık yapma, kalın yazma- gibi işlemleri yapmamızı sağlayan hafif bir işaretleme dilidir.

## README Dosyası Nedir ve Ne İşe Yarar? :
   README, projenin tanıtım kartı ve kullanım kılavuzu gibidir. Depoyu ziyaret eden kişillere projenin ne olduğunu, ne işe yaradığını ve nasıl kullanıldığını anlatır.

## Proje Versiyon/Sürümleri Nedir, Nasıl Belirlenir? :
   Versiyonlar, yazılımın zaman içindeki güncellemelerini takip etmeye yarayan numaralardır (örneğin v1.0.0).
     Genellıkle üç sayıdan olusur:
       * İlk sayı :Çok büyük değişiklikleri (Ana sürüm),
       * Ortadaki sayı :Yeni eklenen (Alt sürüm),
       * Son sayı :Hata düzeltmelerini (Yama) ifade eder.
